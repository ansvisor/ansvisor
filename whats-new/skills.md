A good way of doing a task was hard to repeat the same way every time.
The Skills page lists Ansvisor's skills and your own, each with the connections it uses.
Admins and Managers can save steps as a skill in Chat, or import one from a file or GitHub for review.
Open Skills in the Chat menu, or type / in Chat to use a skill.
